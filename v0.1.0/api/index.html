SoundBank.SoundBank — Module
SoundBank

Easy access to recorded musical instrument notes.

using SoundBank
using Unitful, IntervalSets

bank = UniversityIowaSBank()
piano = instrument(bank, :piano)

c4 = note(piano, "C4")
play(c4)
play(c4, 0.5u"s" .. 2u"s")  # trim before playing

buffer = audio(c4)
samples, sample_rate = buffer.samples, buffer.sample_rate

c_major = chord(note(piano, "C4"), note(piano, "E4"), note(piano, "G4"))
play(c_major)

See the project README for data source attribution and licensing notes.

SoundBank.AudioBuffer — Type
AudioBuffer{T<:AbstractFloat}

Decoded audio: a vector of samples and the sample rate (in Hz) they were recorded at. For multi-channel recordings, samples holds one channel (channel averaging is applied during decoding); see audio.

source
SoundBank.Chord — Type
Chord{S}

Multiple Sounds selected to be played together. A Chord does not hold any decoded audio; call audio to mix the underlying notes into a single AudioBuffer.

source
SoundBank.SBank — Type
SBank

Abstract supertype for a source of recorded notes ("sample bank").

Concrete subtypes must implement:

  • artifact_member_name: how to map an (instrument, pitch, dynamic) selection to the recording name recorded for this bank in recordings.toml.

SoundBank.Sound — Type
Sound{I}

A selected recording: an instrument, a pitch (e.g. "C4"), and a dynamic (e.g. :ff). A Sound does not hold any decoded audio; call audio to retrieve an AudioBuffer.

source
SoundBank.TimeSpan — Type
TimeSpan

A closed interval of Unitful.Time quantities, e.g. 0.5u"s" .. 2u"s", describing a span of audio to keep. Accepted by audio and play to trim a recording.

Endpoints outside the actual duration of a recording (including Inf * u"s") are clamped to the start/end of the recording rather than raising an error; see sample_range.

UniversityIowaSBank

Recordings from the University of Iowa Musical Instrument Samples (MIS) collection. See NOTICE.md for attribution.

SoundBank.animate_playback — Method
animate_playback(buf::AudioBuffer)

Render a spinner + progress animation in the terminal for the duration of buf, redrawing a single line in place until duration(buf) has elapsed.

No-op (returns immediately) when stdout is not an interactive terminal, so it is always safe to call headlessly (e.g. in CI or when output is redirected to a file).

SoundBank.audio — Method
audio(sound::Sound) -> AudioBuffer

Resolve and decode the recording for sound, returning an AudioBuffer of Float64 samples.

The recording is served from a bundled, per-note artifact (see artifacts.jl): installed into the local Julia depot on first use for that specific pitch/dynamic (no network access required thereafter, and other notes' recordings are never downloaded just to play this one). Throws an ArgumentError if no bundled recording exists for the exact pitch/dynamic requested.

Multi-channel recordings are averaged down to a single channel. Decoding errors and unsupported files raise an informative ErrorException.

SoundBank.bundled_note_path — Method
bundled_note_path(sound::Sound) -> String

Local filesystem path to the recording for sound, downloading it first if necessary (only that one recording is fetched, not the whole collection – see module docstring above). Throws an ArgumentError if no bundled recording exists for the exact pitch/dynamic requested. Only resolves a path; call decode_audio_file on the result to load the actual samples.

path = bundled_note_path(note(piano, "C4"; dynamic = :pp))
buffer = decode_audio_file(path)

SoundBank.mix — Method
mix(buffers::AudioBuffer...; average::Bool = true) -> AudioBuffer

Mix two or more AudioBuffers into one by summing their samples.

All buffers must share the same sample rate, or an ArgumentError is thrown. Buffers of different lengths are zero-padded (at the end) to the length of the longest buffer before summing.

By default (average = true) the sum is divided by the number of buffers, which avoids clipping when combining notes whose samples are each already within [-1, 1]. Pass average = false to get the raw sum instead.

SoundBank.note — Method
note(inst, pitch; dynamic = :ff) -> Sound

Select a single recorded note. Validates pitch and dynamic eagerly, raising an ArgumentError for invalid input rather than failing later during download.

Note that the default dynamic is :ff (fortissimo): guitar recordings are only available at :ff, while piano additionally offers :pp and :mf.

c4 = note(piano, "C4")
soft_c4 = note(piano, "C4"; dynamic = :pp)
guitar_a3 = note(guitar, "A3")

SoundBank.play — Method
play(sound::Sound; animate::Bool = true)

Load the audio for sound and play it through the default output device.

While playing, a terminal animation is shown (see animate_playback); pass animate = false to disable it. The animation is automatically skipped when stdout is not an interactive terminal (e.g. in CI or when output is redirected).

SoundBank.play_with_animation — Method
play_with_animation(buf::AudioBuffer; animate::Bool = true)

Send buf to the output device while concurrently showing a terminal VU-meter animation (see animate_playback).

The audio write happens on a separate task (@async) so the animation loop in the calling task can redraw the terminal while playback is in progress. Any exception raised while sending audio to the device (e.g. no output device available) propagates to the caller via wait.

When animate is false, or when stdout is not an interactive terminal, this simply calls send_to_device synchronously with no animation overhead.

Render a width-character track of TRACK_FILL_CHAR, with TRACK_MARKER_CHAR placed at the position corresponding to elapsed_seconds / total_seconds (clamped to [0, 1]), wrapped in [...].

SoundBank.sample_range — Method
sample_range(span::TimeSpan, buf::AudioBuffer) -> UnitRange{Int}

Convert span into a 1-based sample index range into buf.samples.

Endpoints are clamped into [0s, duration(buf)] (so Inf * u"s", or a negative lower bound, are both accepted and simply mean "to/from the end of the recording"). Throws an ArgumentError if, after clamping, the span is empty or inverted.
